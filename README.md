## 👨‍💻 About Me

Beyond tech, I'm a public speaker, debater, and former President of Bahria University Debating Club, passionate about problem-solving, communication and continuous learning.

- 🗄️ **Database Testing:** SQL queries, data validation & integrity checks
- ⚙️ **CI/CD:** GitHub Actions, Jenkins & Git
- 📋 **Test Management:** Jira, Linear, Trello & Azure DevOps
- 🌱 **Currently Learning:** Advanced automation techniques and scalable testing frameworks
